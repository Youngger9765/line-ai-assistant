## 自評

- 最容易被誤解的 PROMPT 指令：`如果訊息沒有明講期限，依照【預設期限規則】填寫`，因為有些期限出現在後續回覆，不在原交辦句
- 不確定怎麼歸類的 fixture：`我可以幫忙看一下，但我要先確認我這週有沒有空`，Vicky 是團隊成員但尚未確定認領
- 跟 README 第三段對得上：有行動表與「沒指定負責人」區塊，欄位包含行動、負責人、期限與原句
