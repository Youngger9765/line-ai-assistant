# 範本 3：會議行動項目

## ① 解決什麼問題（何時用）

開完會習慣在群裡收尾討論、指派工作，但常常沒人整理成一張正式的行動項目表，
過幾天大家就忘了「當初講好誰要做什麼、什麼時候要交」。

這個範本讓 Codex 把會後在群裡的對話，挑出「行動項目」整理成一張表：
誰負責、什麼時候、原話是什麼；沒有明確指定負責人的項目另外列出來，
提醒大家要有人認領。

**什麼時候用**：會議結束、在群裡討論收尾後，說一聲「行動項目」。

## ② 你要改哪幾個字（【】欄位）

- 【團隊成員名單（辨認誰是誰）】：列出你們團隊的成員名字或暱稱，讓 Codex 分得清楚訊息裡提到的人名是不是團隊成員（不是團隊成員的名字提及不當成負責人）。
- 【預設期限規則】：訊息裡沒講清楚期限時，Codex 要怎麼估（例如「沒講期限就填『下次會議前』」或「沒講期限就填『未定』」）。

## ③ 貼上去之後結果長什麼樣

貼上 `PROMPT.md`、換好兩個【】之後，跟 Codex 說「用一次 會議行動項目」再 `sync`，
會得到一張表：行動｜負責人｜期限｜出處（原句），以及一段「沒指定負責人」的項目，
提醒大家認領。範例見 `範例輸出.md`。
