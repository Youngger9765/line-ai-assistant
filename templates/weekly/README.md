# 範本 2：專案群組週報

## ① 解決什麼問題（何時用）

專案群、跨部門群裡一週下來訊息一大串，週五要跟老闆或客戶交代進度時，
還要自己從頭滑回去找「這週到底發生了什麼、決定了什麼」。

這個範本讓 Codex 把一週的群組訊息壓成一份短週報：三件大事、決定了什麼、
還沒定的、下週要做的，最後加一句給老闆看的重點。

**什麼時候用**：每週五說「週報」，或 `sync` 時順便套用。

## ② 你要改哪幾個字（【】欄位）

- 【專案名稱】：週報標題要用的專案名稱，讓 Codex 知道這份週報是寫給哪個專案看的（例如「網站改版專案」）。
- 【週報給誰看（口氣）】：影響用詞正式程度，例如「給客戶看，正式一點」或「給team內部看，輕鬆一點」。
- 【固定要有的欄位】：除了預設的三件大事／決定／待定／下週外，你還想固定看到哪些欄位（例如「風險」「預算異動」），沒填就用預設四欄。

## ③ 貼上去之後結果長什麼樣

貼上 `PROMPT.md`、換好三個【】之後，跟 Codex 說「用一次 專案群組週報」再 `sync`，
會得到一份 ≤300 字的週報：本週三件大事、決定了什麼、還沒定的、下週要做、
最後一句「需要老闆知道的一句話」。範例見 `範例輸出.md`。
