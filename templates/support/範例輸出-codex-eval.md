## 自評

- 最容易被誤解的 PROMPT 指令：`目前已經過了幾小時沒回`，因為 fixtures 沒有明確給 sync 當下時間
- 不確定怎麼歸類的 fixture：`王小姐不好意思，退貨申請請填這個表單，我們會在3天內處理`，它可能同時回答申請方式與處理天數，但沒有明確回答林先生的期限問題
- 跟 README 第三段對得上：有已回與未回兩張表，未回含幾小時沒回與建議回法，重複退貨申請合併計次
