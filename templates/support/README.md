# 範本 4：客服整理

## ① 解決什麼問題（何時用）

客服群、一對一客戶群一整天下來訊息很多，收工前想確認「客戶問過什麼、
我們回了沒有、還有哪些漏掉沒回」，靠人工滑訊息很容易漏掉。

這個範本讓 Codex 把一天的對話整理成兩張表：已回的問題與回覆摘要，
以及還沒回的問題（附上已經幾小時沒回、建議怎麼回一句），
重複被問到的問題會合併計次，讓你知道哪個問題最多人問。

**什麼時候用**：每天收工前說「客服整理」。

## ② 你要改哪幾個字（【】欄位）

- 【我方人員名單（分辨客戶 vs 我方）】：列出你們客服/我方人員的名字或暱稱，讓 Codex 能分辨訊息裡誰是客戶、誰是我方回覆的人。
- 【回覆 SLA 小時】：超過幾小時沒回算是「該優先處理」，填一個數字（例如「4」代表 4 小時內沒回要標出來）。
- 【常見問題分類】：你想讓 Codex 用哪些分類去歸類問題（例如「退換貨、出貨進度、帳號問題」），沒填就讓 Codex 自己歸類。

## ③ 貼上去之後結果長什麼樣

貼上 `PROMPT.md`、換好三個【】之後，跟 Codex 說「用一次 客服整理」再 `sync`，
會得到兩張表：**已回**（問題→回覆摘要）與**未回**（問題｜幾小時沒回｜建議回法一句），
重複問題會合併計次。範例見 `範例輸出.md`。
