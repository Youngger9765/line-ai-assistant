## 自評

- 最容易被誤解的 PROMPT 指令：`訊息裡出現【急件關鍵字】這些字眼的事項，挑出來放在整份清單最上面`，因為「不急」含有急字但語意不是急件
- 不確定怎麼歸類的 fixture：`下週三的簡報時間我幫你排好了`，它回覆了排時間這件事，但不是阿明自己完成
- 跟 README 第三段對得上：有「這三天最急」、待辦清單、已完成，且每項都有事項、誰給的、期限、來源群
