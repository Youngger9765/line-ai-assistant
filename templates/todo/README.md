# 範本 1：個人待辦

## ① 解決什麼問題（何時用）

你同時在好幾個群裡——家庭群、工作群、自己傳自己的備忘群——待辦事項散在各處，
常常事後想不起來「那件事是誰交代的、到底有沒有期限」。

這個範本讓 Codex 把你指定的幾個群，掃過去挑出「別人交代給你」或「你自己說要做」的事，
收成一張清單，並把快到期或帶急件字眼的事項挑到最上面。

**什麼時候用**：你說「sync」的時候順便套用；或每天早上先看一眼今天要做什麼。

## ② 你要改哪幾個字（【】欄位）

貼進 `PROMPT.md` 之前，把下面三個【】換成你自己的：

- 【我的名字／暱稱】：Codex 要知道「誰是你」，才能分辨一句話是別人交辦給你、還是你自己隨口提到別人的事。填你在群裡別人怎麼稱呼你（例如「阿明」「Emma」）。
- 【哪些群算待辦來源】：不是每個群都該收進待辦，例如純聊天群就該排除。列出你要 Codex 掃描的群組名稱（例如「家庭群、專案A工作群」），沒列到的群不會被收進來。
- 【急件關鍵字】：出現這些字的訊息會被判定是「這三天最急」，往清單最上面放。填你自己會用的急件字眼（例如「明天、緊急、deadline、趕快」）。

## ③ 貼上去之後結果長什麼樣

貼上 `PROMPT.md`、換好三個【】之後，跟 Codex 說「用一次 個人待辦」再 `sync`，會得到像 `範例輸出.md` 那樣的一張清單：最上面是「這三天最急」，接著是待辦清單（事項｜誰給的｜期限｜來源群），最後是已完成的另外列一段，方便你確認哪些已經處理掉了。
