# 範本 5：學習筆記／資料庫

## ① 解決什麼問題（何時用）

你把看到的好文章網址隨手丟進一個自己收藏的群、或讀書會群，時間久了想回頭問
「我最近在關心什麼」「這個月學到了什麼」，卻只剩下一長串網址找不到重點。

這個範本讓 Codex 把這些網址整理成一份資料庫（日期、標題、來源網域、一句摘要、
你當時的註記），再加上一份週回顧（三個主題、一個沒想到的連結、下週想追的）。

**現在的功能**：只要群裡的文字訊息含網址，收訊當下就會自動抓該頁的標題與描述
存起來，**不是抓全文**——所以 Codex 整理時看到的是標題／摘要，不是網頁完整內容；
如果你想看全文，要請 Codex 自己再開一次那個網址（要看它當下的網路權限允不允許）。
私人連結（需要登入才看得到的頁面）只會留下網址本身，標題與摘要會是空的。
**只抓公開網頁的標題與描述，私網／內部位址（例如區網 IP、`localhost`）不抓**，這是安全設計，不是漏掉。

**什麼時候用**：週末說「學習筆記」或「我最近在關心什麼」。

## ② 你要改哪幾個字（【】欄位）

- 【我的關注領域（幫它分主題）】：列出你平常關心的幾個主題方向（例如「AI 應用、教育、投資理財」），讓 Codex 用這些主題去歸類你收藏的連結，而不是自己亂分。
- 【回顧週期】：多久幫你做一次週回顧（例如「每週」或「每兩週」），影響 Codex 統計主題與抓「一個沒想到的連結」的時間範圍。

## ③ 貼上去之後結果長什麼樣

貼上 `PROMPT.md`、換好兩個【】之後，跟 Codex 說「用一次 學習筆記／資料庫」再 `sync`，
會得到兩層結果：一層是**資料庫**（日期｜標題｜來源網域｜一句摘要｜你當時的註記），
一層是**週回顧**（三個主題／一個沒想到的連結／下週想追的）。範例見 `範例輸出.md`。
